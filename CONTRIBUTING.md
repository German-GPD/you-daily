## 🇬🇧 English
You Daily is currently a private, early-stage project. Contributions are not open by default.

- Repository access does not grant permission to reuse code, designs, documentation or brand materials.
- Submit third-party material only if you have the right to use it and can identify its license.
- Never include credentials, personal data or confidential information in commits.
- Work on the project only when explicitly invited by the owner.
- Before accepting external work, agree in writing on ownership, permitted use, confidentiality and attribution.

A contribution does not automatically transfer copyright or grant a license to the project. Those terms must be agreed explicitly.

Сам факт внесения вклада автоматически не передаёт авторские права проекту и не предоставляет ему лицензию. Эти условия нужно согласовать отдельно.
